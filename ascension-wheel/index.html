05 — About this case study

One system, re-skinned per brand

User acquisition & retention tool. “Spinner Winner” drives engagement through an achievement-to-prize system — the real design problem was keeping one visual system flexible enough to be re-skinned per partner brand without ever touching the mechanic underneath.

Three concentric rings, any number of segments per ring, value always reading clearer toward the center no matter the theme. Everything below is a real production asset running on the live rig, so switching themes swaps the whole visual language while the underlying geometry never moves.
